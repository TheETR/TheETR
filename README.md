## About Me

I'm an Electrical & Electronics Engineering student from Türkiye, working on software at the intersection of engineering, product design and ambitious systems architecture.

I build AI-powered automation, real-time media tools, developer infrastructure and progression-focused game systems.

I prefer complete products over isolated demos.

## Currently Building

### ELALEM

An **AI-powered modular automation ecosystem** designed for Discord communities.

It combines music, moderation, economy, entertainment and AI-driven interactions inside a scalable modular architecture.

`Node.js` · `discord.js` · `Prisma` · `AI Systems` · `i18n`

### Retake

A capture, replay and editing platform focused on making high-quality recording workflows simpler and more accessible.

`Real-time Media` · `Desktop Software` · `Cloud Infrastructure` · `Product Engineering`

### THEE Shell

A shell-independent developer environment designed to provide a consistent command layer and workflow across different shells and Linux environments.

`Shell Tooling` · `Linux` · `Developer Experience` · `Command-Line Systems`

### Continuum Engine

An experimental systems architecture project exploring distributed memory, continuity mapping and long-term information preservation.

It is planned to eventually converge with **Continuum Neurotics** as part of a broader continuity-oriented system.

`Systems Design` · `Distributed Architecture` · `Research`

## Selected Public Projects

### [TheE's-DDW](https://github.com/TheETR/TheEs-DDW)

A Windows-first domain lifecycle monitor with adaptive RDAP polling, verified drop detection, local alerts and optional Discord notifications.

`PowerShell` · `RDAP` · `Windows` · `SQLite` · `Discord Webhooks`

### [TheeDiscordMCP](https://github.com/TheETR/Thee-Discord-MCP)

A safety-gated local MCP server for inspecting and managing allowlisted Discord servers through Discord's official REST API.

`TypeScript` · `Node.js` · `MCP` · `Discord REST API` · `Safety Controls`

### [ConfigStackMC](https://github.com/TheETR/ConfigStackMC)

Tools and configurations for building maintainable Minecraft server environments.

`Minecraft` · `Server Tooling` · `Configuration` · `Automation`
